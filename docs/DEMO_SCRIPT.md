# 90 秒功能演示

视频以本机真实产品界面截帧剪辑，附中文字幕；不是连续屏幕录像。后端界面显示真实 FastAPI/LangGraph 已连接，运行默认确定性研究模式，没有伪装实时模型推理。

| 时间 | 界面与讲解 |
|---|---|
| 00–12 秒 | 产业图谱：以固态电池为例，六家公司、七条业务关系，材料是历史快照 |
| 12–27 秒 | Solid Power 收入证据：约 1,180 万美元来自产线安装与技术转移；电解质研发关系仍 B |
| 27–41 秒 | 跨市场：赣锋与 QS 可以比研发/导入阶段，但半固态与陶瓷隔膜平台、业务模式不能混用 |
| 41–57 秒 | 原料降价：查看原料、半固态电芯、整车三个条件性传导分支，保留库存与售价反向机制 |
| 57–69 秒 | 敏感度：拖动转移比例，所有数值均为假设，结果不是公司盈利预测 |
| 69–80 秒 | 证据台账：来源、定位、日期、摘要校验和人工更新流程；快照可导出与比较 |
| 80–90 秒 | 异常边界：未知产业拒绝；过早证据截止得到 M；不提供买卖建议或目标价 |

推荐现场复现：启动后端 → 点击工艺许可与产线工程 → 打开收入原文 → 跨市场 → 传导路径 → 证据页 → 把产业输入改为“固态电池目标价”验证拒绝 → 改回固态电池。
