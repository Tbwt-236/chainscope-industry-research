## 浏览器实测

通过 Codex 浏览器实际操作，而非仅检查源代码：

1. 本机 8000 页面明确显示 FastAPI / LangGraph 已连接；查看真实收入作用域、原始 URL 与年报定位。
2. 核验两组对照文字，并核对 QS 原型含液态 catholyte 的技术边界。
3. 查看传导分支与成立条件；通过键盘将降本转移比例设为 100%，结果实际显示 0.00 pp。
4. 目标价请求显示拒绝，并明确保留的是上一次成功快照。
5. 证据截止改为 2023-01-01，全部关系显示 M，无法读取未来财报金额。
6. 手机视口 390×844：文档宽度实际为 390，无整页横向溢出；检查后已恢复正常视口。
7. 独立 8080 模式显示浏览器规则引擎；真实年报复核摘要导入后先待审，人工确认后来源数 7→8；刷新页面仍为 8，待审为 0。该额外记录仅为本机 UI 验证，不更改发布样本。
8. 优化后实际填写表单、导入真实 QS 2025 年报样本、待审、确认复核、调整截止、查看差异；界面显示“新增来源”与“等级保持 B”。录制十个步骤均校验预期可见状态。
9. 全固态筛选 → 量产延期：界面保留 Solid Power 与工艺许可/产线分支，排除 QS；不会因另一公司被筛掉而丢弃整个有效分支。
10. 优化表单 390×844 视口：文档宽度 390，弹窗宽度 350，内容宽度 348；收入类型切换显示金额、币种、期间与范围。检查后恢复默认视口。
11. 主演示 `ChainScope_Task1_live_demo.mp4` 为连续浏览器屏幕采样，138 张真实帧、72.751 秒，按原始时间戳编码。采样约 2 fps；输出 24 fps 不代表原始录制 24 fps。无旁白，无虚构帧，字幕概括操作。旧 90 秒截帧剪辑保留为补充。截图见 `docs/screenshots`。

- 未连接真实扶摇/iFinD 或兼容在线模型；模型成功与失败门控采用 HTTP mock，不能据此宣称真实联调通过。真实验证脚本已执行，配置缺失，记录为 `not_configured`，没有发送请求。
- 未做生产负载、渗透测试、跨设备同步或独立研究员标注质量评估。
- 通用技能审计原始结果见 `generic-skill-audit.json`。其海关 HS、Milvus 混合检索、冷热存储和短文字数规则不适用于本项目，因此不声称通用脚本整体通过。
