## 开发记录

| 环节 | AI 工作 | 采用前的验证 |
|---|---|---|
| 需求与 SDD | 读取用户附件，整理提交要求与系统边界 | 对照四条提交要求建立规范覆盖矩阵 |
| 证据评级 | 设计关系级 A/B/C/D 与独立 M、冲突状态 | 同公司不同环节、缺金额、未来证据与篡改测试 |
| 实现 | 生成 FastAPI、真正 LangGraph、SQL 仓储、前端及浏览器参考引擎 | 实际安装依赖、执行 Python/JS 测试与本机浏览器交互 |
| 数据 | 搜索官方公开材料，人工核对摘要、定位、日期、财务业务范围 | 原始官方页面与 SEC 申报索引核对；未把搜索结果排名视为真实性证明 |
| 研究表达 | 草拟可比差异与传导模板 | 每个判断标注背景来源、成立条件、反向机制及未获支持范围 |
| 交付 | 文档、视频演示脚本与打包 | 文件可打开、视频时长/编码、部署状态验证 |

运行时默认没有调用 LLM。LangGraph 是编排框架，节点可以执行规则；此处不把规则链称为已经接入多个独立大模型。可选模型仅参与已有证据 ID 的排序，不获准新增断言。

## 被修正的风险

- 删除“没有财务数字就自动降 C/D”的错误规则：有研发证据维持 B，无证据为 M。
- 删除公司整体评级：同一公司各环节和技术路线分别评级。
- 不引用集团锂电池收入作为固态电池收入。
- 不将半固态与凝聚态标为全固态。另核对 QS 年报中液态 catholyte 事实，将其单列固态隔膜路线。
- 不把研发许可/安装工程收入称为电芯规模销售，不根据约数计算收入占比。
- 传导引用只支持背景，不声称证据直接证明价格事件、关税已发生或具体财务增幅。
- 成本计算输出固定基期收入的毛利额贡献，不误称变化后分母下的毛利率。
- 新证据进入待审区；摘要哈希不能替代原文真实性验证。
- 图中连接来自实际 `edges`；没有把所有环节顺序摆放便误画成线性交易链。

## 尚未验证

真实金融数据 API、真实兼容在线模型、PostgreSQL 容器、多用户并发、生产负载、人工标注研究准确率。代码测试验证的是实现约束，不能证明全部金融研究结论正确。
